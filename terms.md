# Terms of Use

**Project:** SUBU Telehealth Comment Analysis  
**Last updated:** 22 November 2026

1. **Nature of the project.** SUBU Telehealth Comment Analysis is a non-commercial academic research project of the Department of Health Management, Sakarya University of Applied Sciences (SUBU), Türkiye. It is not a public application or service, and it has no end users other than the research team.

2. **YouTube Terms.** The project uses YouTube API Services. Use of YouTube data by this project is subject to the [YouTube API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service), the [YouTube API Services Developer Policies](https://developers.google.com/youtube/terms/developer-policies), the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

3. **Permitted use.** Data collected by the project is used only for academic analysis and for publications reporting aggregate results. The research team does not use the data for commercial purposes, advertising, or monitoring individuals.

4. **No redistribution.** Raw YouTube data collected by the project is not redistributed, sold or published. Only aggregate, non-identifiable findings are shared in scientific publications.

5. **Read-only access.** The project only reads public data. It does not upload, post, modify or delete any content on YouTube and does not interfere with YouTube playback or advertising.

6. **Data protection.** Data is handled as described in the [Privacy Policy](privacy.html), including pseudonymisation of authors and refresh or deletion of stored data within 30 days.

7. **No warranty.** The project page and published findings are provided for scientific information only and do not constitute medical advice.
