# Privacy Policy

**Project:** SUBU Telehealth Comment Analysis  
**Responsible researcher:** Assoc. Prof. Dr. İsmail Şimşir, Sakarya University of Applied Sciences (SUBU), Türkiye  
**Last updated:** 22 November 2026

## 1. Use of YouTube API Services

This project uses YouTube API Services (YouTube Data API v3) to collect publicly available data for academic research. People whose public YouTube content is collected by this project are subject to the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's collection and use of data is governed by the [Google Privacy Policy](https://policies.google.com/privacy) (http://www.google.com/policies/privacy).

## 2. What data is accessed

The project accesses only public information through read-only API calls:

- Video data: video ID, title, description, channel name, publish date, and view, like and comment counts.
- Comment data: comment text, publish date, like count, reply count, and the author's display name and channel ID as returned by the API.

The project does **not** access private videos, private messages, account settings or any data that requires a user to sign in. It does not use OAuth and never asks anyone for access to their Google account.

## 3. How the data is used

The data is used only to produce aggregate scientific findings (for example topic frequencies and sentiment distributions) for a peer-reviewed research article on public perceptions of telehealth. It is not used for advertising, profiling individuals, marketing or any commercial purpose.

## 4. Pseudonymisation and publication

- Author display names and channel IDs are replaced with irreversible pseudonymous codes as soon as the data is collected, and the original identifiers are not kept in the analysis files.
- Results are reported only in aggregate. If a short excerpt is needed to illustrate a theme, it is paraphrased or shortened so that it cannot be traced back to its author through search.

## 5. Storage, retention and deletion

- Data is stored on access-restricted storage used only by the research team.
- In line with the YouTube API Services Developer Policies, stored API data is refreshed or deleted within **30 days** of collection. Data that can no longer be refreshed (for example comments that have been removed from YouTube) is deleted.
- When the analysis is finished, all raw API data is deleted. Only aggregate, non-identifiable results are kept for publication.

## 6. Sharing

The data is not sold, rented or shared with third parties. It is not combined with data from other platforms. Raw data is not published or deposited in public repositories.

## 7. Cookies and tracking

This website and the data collection tool do not use cookies or tracking technologies and do not collect any information about visitors.

## 8. Your choices and contact

If you believe a comment of yours has been collected and you would like it removed from the research dataset, please contact the researcher at **ismailsimsir@subu.edu.tr**. Requests are handled within 7 days. Removing or editing a comment on YouTube also removes it from this project at the next refresh.

Although this project does not request access to any Google account, you can review and revoke any app's access to your Google account at any time through the [Google security settings page](https://security.google.com/settings/security/permissions).

## 9. Changes

Any changes to this policy will be published on this page with a new "Last updated" date.
