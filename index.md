# SUBU Telehealth Comment Analysis

**SUBU Telehealth Comment Analysis** is a non-commercial academic research project carried out at the Department of Health Management, Faculty of Health Sciences, Sakarya University of Applied Sciences (SUBU), Türkiye.

The project studies how the public talks about telehealth (remote healthcare delivered through video, phone and mobile tools) in the comment sections of YouTube videos. The results will be published as a peer-reviewed research article.

## What the project does

- Identifies YouTube videos with a fixed list of 27 English and 30 Turkish telehealth keywords (for example *telehealth*, *telemedicine*, *remote patient monitoring*, *telesağlık*, *online muayene*).
- Records up to the first 100 videos returned for each keyword.
- Collects the **publicly available** comments and replies on those videos, together with basic video metadata (title, publish date, view and comment counts).
- Analyses the comments **in aggregate** with text-mining methods (topic modelling and sentiment analysis) to describe themes such as access, trust, privacy, cost and quality of remote care.

## What the project does not do

- It has no public user interface, no user accounts and no Google sign-in (OAuth). It is run only by the research team.
- It does not post, edit, delete or reply to anything on YouTube.
- It does not sell, share or advertise with the data, and it does not combine YouTube data with data from other platforms.
- It does not publish individual comments in a way that identifies their authors.

## YouTube API Services

This project uses **YouTube API Services** (YouTube Data API v3). By being part of data collected through this project, YouTube users are subject to the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

API methods used: `search.list`, `videos.list`, `commentThreads.list`, `comments.list` (read-only).
